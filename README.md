# 每次 · 健身打卡

个人健身打卡与健身卡成本分析，支持离线使用。

访问：https://ougggg.github.io/gym-check-in/

- 固定期限健身卡；月卡、季卡、半年卡、年卡与自定义时长。
- 手动打卡、补录和撤销，统计累计、周、月次数及单次成本。
- 成本趋势可切换近 30 天 / 整个周期，逐次查看；按当前卡费重算，无日期历史次数仅作基数。
- 到期成本按每周 2、3、4 次进行情景估算，新增次数按剩余有效期向下取整。
- 有未导出改动或距上次生成备份满 7 天时提醒；生成下载后请确认文件已保存。
- 数据仅保存在当前浏览器本机，可在卡片页导出和导入备份。
- 换设备、浏览器或网址前请先导出备份，个人备份文件不要上传到本仓库。

本仓库为可直接发布的静态网页，无需安装依赖或构建。GitHub Pages 使用 main 分支根目录。修改网页资源后同步更新 sw.js 缓存版本，关闭旧页面后重新打开以启用新版。
